# Smart Campus & University Network

## Overview

Designed and configured a campus network with multiple departments and segments. The project focuses on network segmentation, routing, network services, and access control to provide reliable inter-department communication.

## Technologies

- VLANs
- OSPF
- DHCP
- ACLs
- NAT
- DNS
- Inter-VLAN Routing

## Tool

Cisco Packet Tracer 8.2.2
